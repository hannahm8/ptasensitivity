

This is an initial approach to see if we can gain SNR by reorganising how observation time is split between the pulsars. 
We shuffle time between pulsars keeping the total available time to MeerTime constant. 
We assume that the observation cadence is unchanged $c=26\,{\rm yr}^{-1}$ and compute the SNR after $10\,{\rm yr}$. 
The constraint is that we have a total observing time of 
\begin{equation}
\sum_{I} T_{{\rm obs},I} = 42\,592\,{\rm s}\,,
\end{equation}
available for the $82$ pulsars every two weeks. 
This then feeds into the precision achieved in Eqn.~\ref{eqn:TobsToSig} and the resulting SNR of the array in Eqn.~\ref{eqn:snrPIPJPg}.


As a first pass we trial reallocating time in $1/4 T_{{\rm obs},I}$ units. 
We trial subtracting $1/4 T_{{\rm obs},I}$ from pulsar $I$ and adding that time to pulsar $J$ for $I\neq J$.
Having tried all possible combinations, we save the best set of $T_{\rm obs}$ (the one that gives the highest value of Eqn.~\ref{eqn:snrPIPJPg}) and repeat.  


\subsection{Angular correlation functions}
We also try using three different functions for $\chiIJhd$ for the time reallocation as maximising equation~\ref{eqn:snrPIPJPg} may not totally capture a desired observing strategy for PTAs. 


\subsubsection{Hellings-Downs}
The Hellings-Downs function, Eqn.~\ref{eqn:hd} is how we expect the gravitational wave signal to appear in pulsar pairs. 
It is shown as the blue line inf Fig.~\ref{fig:correlations}.
It is important for a PTA to have good coverage of a range of angular separations between pulsar pairs so that a gravitational-wave detection can be confirmed. 
However, if we use the Hellings-Downs function in our SNR calculation, we find that we favour pulsars in the galactic centre where the angular separations are small and the value of Eqn.~\ref{eqn:hd} is largest. 

\subsubsection{Dipole $-$ Hellings-Downs}
As we want to keep pulsar pairs with large angular separations we also try maximising a modified Eqn.~\ref{fig:correlations} with a different $\chiIJhd$. 
One option is to use the difference between Hellings-Downs function and a dipole, 
%Eqn.~\ref{eqn:hd} has highest values for pulsars that have small angular separations.
%But we want good sky coverage to confirm a Hellings-Downs correlation for detection. 
%To prevent the time-shuffle algorithm favouring pulsars in the galactic centre, we replace the Hellings and Downs correlation $\chiIJhd$ with a modified angular correlation function $\chi_{IJ}^{\rm mod}$ which corresponds to the difference between a dipole $\chiIJdip$ and the HD correlation
\begin{equation}
\chi_{IJ}^{\rm mod} = \chiIJdip - 2 \chiIJhd
\label{eqn:chimod}
\end{equation}
where $\chiIJdip$ is given by~\cite{AnholmEtAl:2009}
\begin{equation}
\chiIJdip = -\frac{3}{2}
            \left[ \cos \zeta - \frac{4}{3} - 4 \tan^2 \frac{\zeta}{2} 
                   \ln \left( \sin \frac{\zeta}{2} \right) \right]\,.
\label{eqn:dip}
\end{equation}
The resulting function now favours large angular separations between pulsars and is shown as the green line in Fig.~\ref{fig:correlations}. 

\subsubsection{Equal value}
A third option is to have no preference for any angular separation and set $\chiIJhd$ to a constant value for all pulsar pairs.

\subsection{Results}

Results of our time reallocation method are shown in Fig.~\ref{fig:snrCompare}.
The original observation stragegy is shown by the blue-solid line.
The results of the three different angular correlation functions are shown.
The orange-dotted line shows the results of using the Hellings-Downs function. 
The green-dasshed line shows the result of using the dipole minus Helllings-Downs function. 
The red-dot-dashed line shows the results of using all equal values for angular correlation. 
(The different functions are only used for the time reallocatoin algoritm, the plot shows the actual SNR value using the Hellings-Downs function as in Eqn.~\ref{eqn:snrPIPJPg}).

Using the Hellings-Downs function is the best performing, but comes at the cost of losing pulsar pairs at high angular separation.
The equal-values is the next best and provides and SNR improvement of $\approx 1$ after $10\,{\rm yrs}$.
