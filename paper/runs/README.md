# Notes for results

The compressed directories in this folder contain the results used in the paper. 

- `main_runs/` : the main results used in the paper. 
   - `hd.tar.gz`    : time swap analysis using the HD correlation function as described in the paper. 
   - `dphd.tar.gz`  : time swap analysis using the DPHD correlation function as described in the paper.
   - `equal.tar.gz` : time swap analysis using the Equal correlation function as described in the paper.

- `extraTime_runs/` : the results used in section 6 of the paper in which we increase the observing time allocated to MPTA and the perform the time swap analysis. The names of the files indicate the amount of extra time and the correlation function used, e.g. `equal_1.8.tar.gz` indicates an analysis using the equal correlation function and 80% extra time (1.8). The files included are:
   - `hd_1p2.tar.gz`
   - `dphd_1p2.tar.gz`  
   - `equal_1p2.tar.gz` 
   - `equal_1p3.tar.gz`
   - `equal_1p4.tar.gz` 
   - `equal_1p5.tar.gz`
   - `equal_1p6.tar.gz`  
   - `equal_1p7.tar.gz`
   - `equal_1p8.tar.gz` 
   - `equal_1p9.tar.gz`
   - `equal_2p0.tar.gz`
